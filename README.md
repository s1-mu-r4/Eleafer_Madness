# Eleafer Madness

Custom firmware research for Eleaf/Joyetech-class devices.

This repository is reserved for an **independent firmware concept**. Device support, implementation, release artifacts, and on-device safety have not yet been established.

Work derived from an existing open-source firmware should be developed in a fork of that firmware's repository, preserving its upstream history and license.

No flashing instructions or firmware releases are provided here.
