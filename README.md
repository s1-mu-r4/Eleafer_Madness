## 現在の作業：Ron7版 `pufflimit` のE115実機確認

対象は [wighawag/myevic `08202453b54c2284df27c9f188f66c2b2fb0f92e`](https://github.com/wighawag/myevic/tree/08202453b54c2284df27c9f188f66c2b2fb0f92e)。**既存のRon7版を安全に実機で検証できる条件を整え、元の機能が動作するか評価する**ことが目的。

- 対象範囲：固定ソースのビルド・バイナリ適合、既存安全機能、実機の読取専用識別、純正復旧手段、Ron7版の最小限の不具合修正、将来の実機テスト手順。
- 対象外：DOPEY専用の週間・直近60分制限、永続パフログ、追加16KiB、Android ACK、独自の製品仕様への改変。Ron7既存のパフ数制限・時計関連動作をDOPEYの仕様で判定しない。
- 実機へのファームウェア書き込みは**NO-GO**。静的監査でスタック超過等の不合格があり、復旧の実書き込みも未確認。分解・SWD・Nu-Linkは使用しない。
- ユーザーの明示的な承認なしに、実機書込、保護解除、CONFIG変更、mainへの機能マージを行わない。

調査記録はこのリポジトリに保存する。過去の調査が別リポジトリに混入した事実は履歴として記録するが、今後のRon7検証作業をDOPEYのPRへ追加しない。
